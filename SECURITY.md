# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `k8s-subvol-provisioner`, please do **not** open a public issue.

Instead, please report security vulnerabilities via:
- [GitHub Security Advisories](https://github.com/blesswinsamuel/k8s-subvol-provisioner/security/advisories/new)
- Or contact the maintainers directly via email.

Please provide a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept material. We will review and address reported issues promptly.
